# DictionaryTUI
A lightweight (~40kB) terminal interfacing flashcard program written completely in python. Can be used for question/answer, term/definition, word/translation, and etc.


# LIBRARIES

os, shutil, random, time, Path


# USAGE

Application is ran completely through Dictionary.py:
```bash
python Dictionary.py
```

All files (dictionaries) are stored within the subdirectories (archives) of the Logs directory in the form of .txt files. General formatting of dictionaries is viewable in the already present sample documents.
